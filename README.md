# DevGuide: Practical Technical Documentation

DevGuide is a beginner-friendly technical writing portfolio project. It explains core web-development concepts using plain language, step-by-step instructions, and practical examples.

## What you'll learn
- What a REST API is and how a client communicates with a server
- How HTTP methods and status codes work
- How to make API requests with `curl`
- How to troubleshoot common request errors

## Documentation
| Guide | Description |
|---|---|
| [REST API basics](docs/rest-api-basics.md) | Understand endpoints, requests, responses, and JSON |
| [HTTP status codes](docs/http-status-codes.md) | Learn common status codes and troubleshooting |
| [Testing requests with curl](examples/testing-requests-with-curl.md) | Try API requests from a terminal |

## Who this is for
This handbook is for beginners learning how web applications communicate. Each guide defines unfamiliar terms, gives examples, and explains how to diagnose common problems.

## Project status
Educational documentation project. Review and test examples before relying on them in production.

## How to contribute
1. Choose a guide that could be clearer or more complete.
2. Make a focused edit and include an example where useful.
3. Check that commands and URLs are clearly labeled.
4. Submit a pull request describing what changed and why.
